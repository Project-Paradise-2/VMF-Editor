# TDU2 VMF Editor

A tool for viewing, inspecting and editing **VMF (Eden Flash)** files used by **Test Drive Unlimited 2**.

The editor is designed to help developers and modders explore the game's original Flash-based UI resources and work with their internal structure.

## Features

- Load and inspect VMF files
- Explore Eden Flash resources
- View file structure and available elements
- Edit supported VMF data
- Save modified files
- Designed for TDU2 modding and reverse engineering

*Features and supported editing capabilities may vary depending on the VMF file and its internal structure.*

## Installation

1. Download the latest release.
2. Extract the archive.
3. Run `VmfEditor.exe`.

No additional installation is required.

## Usage

1. Start the VMF Editor.
2. Open a VMF file from your Test Drive Unlimited 2 installation (Complete .bnk).
3. Inspect its contents and internal structure.
4. Make the desired modifications.
5. Save or export the modified file.

Always keep a backup of the original VMF files before making changes.

## File Format

VMF files are used by Test Drive Unlimited 2 as part of its Eden Flash-based user interface system.

These resources contain data used by the game's original Flash UI elements.

This editor aims to make these resources more accessible for inspection, modification and modding purposes.

## Compatibility

- Game: Test Drive Unlimited 2
- Format: VMF (Eden Flash)
- Platform: Windows
